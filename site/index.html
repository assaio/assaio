Open-source, offline analysis

See what your AI coding tools cost and produce

assaio is an open-source CLI for logs from Claude Code, Codex CLI, Gemini CLI, GitHub Copilot CLI, Cline, and Antigravity CLI. It reports per-project activity, output, and directional local outcomes offline. Every figure states its basis; Antigravity contributes activity only because its logs lack tokens and project data.

Beyond token counts

Questions your logs can answer

assaio reports output and directional local outcomes. It reads diffs and file bodies for counts only, stores neither, extracts no prompts or responses, and never stores a full path.

Which projects turn tokens into code?

Effectiveness shows AI-written lines against estimated cost, per project. Line counts are complete for Claude Code and Codex CLI only.

outputeffectiveness

How much work uses premium models instead of cheaper ones?

Model fit shows premium versus cheaper model share. reprice changes only price arithmetic for recorded turns; it cannot predict another model's output.

activitymodel-fitmodel-right-sizing

Does a flat plan fit your usage?

Subscription fit projects your observed API-equivalent estimate to a calendar month and compares it with the plan price you configure. It cannot read plan consumption.

activitysubscription-fit

Where does your context window go?

Context health shows cache reuse, session depth, and compaction. These describe activity; they do not measure lasting code or impact.

activitycache-hygienecontext

Where does your AI work get revised or stuck?

Rework, edit loops, failed tool calls, and declined proposals reveal patterns in your logs. A pattern is a prompt to inspect, not a fault finding.

outputreworkactivityedit-loopsfriction

Does code from recent commits last?

Survival checks which code from recent commits remains in HEAD without attributing lines to individual AI sessions. Session-to-commit matches are candidates, not proof. Bug impact and quality are not measured yet.

outcome · directionalsurvivalattributionevidence

Not measured yet

  • Attributable survival — whether code linked to an AI session lived on in main after review, rewrites and reverts.
  • Bug impact — whether it caused bugs, only ever against age-matched human code.
  • Quality — maintainability, alongside DORA- and DX-style signals.

How it works

  1. Install the binary

    Install the single static Go binary with brew install assaio/tap/assaio-agent or go install github.com/assaio/assaio/cmd/assaio-agent@latest.

    brew install assaio/tap/assaio-agent

  2. Run assaio-agent init

    assaio-agent init detects tools, shows every directory before reading it, imports your logs, then writes the report in about sixty seconds.

    assaio-agent init

  3. Read your reports

    report prints tokens and estimated cost by project/model/tool/day. analyze states what grounds each directional read and withholds unsupported grades. dashboard writes one self-contained offline HTML file.

    assaio-agent analyze

Privacy and limits

What assaio keeps and refuses

assaio makes its limits clear. Local analysis stays on your machine. Repository content is counted but not stored. People are not ranked, and uncertain figures are labeled.

Local analysis runs offline

Local analysis needs no account and sends no telemetry or uploads. Only sync and serve, for the self-hosted team server, and runtime inspect use the network.

No ranking of people

assaio refuses --by member in every format and builds no ranking. On the team server, a member panel shows engagement while output and spend stay the team's total. Members have stable pseudonyms by default. report --identify names individuals and says so in its output.

No invented numbers

assaio prints no “time saved” figure: logs hold no counterfactual. A model missing from the price table shows —, never $0, and stays out of totals. Every dollar amount is an estimate at public pay-as-you-go prices, not your bill.

Content is counted, not kept

Repository content in diffs and file bodies is read only for counts and never stored. Prompts and model responses are not extracted. The store keeps a project basename and a path relative to the repository root, never a full path.

Corrections with a post-mortem are documented in the public docs/corrections.md register, with the incorrect number and the release that fixed it. Corrections register →

Six supported AI coding tools

Line counts are complete only for Claude Code and Codex CLI. GitHub Copilot CLI reports changed lines for the whole session. Gemini CLI and Cline contribute cost without line counts. Antigravity CLI records edits and tool calls but no tokens or project, so it is absent from per-project figures.

Frequently asked questions

What does assaio measure?

assaio measures activity, such as sessions and tool mix; output, such as line changes and rework; and directional local outcome checks. survival measures how much code changed by recent commits remains in HEAD. Bug impact, quality, and attributable survival after review are not shipped.

How is assaio different from ccusage?

ccusage describes itself as tracking tokens and estimated costs across 15+ agent tools, more than assaio's six. assaio documents output measures and directional local outcome checks per project, a store you keep, and a self-hosted team server.

Does assaio send my data anywhere?

Local analysis runs offline with no account, telemetry, or upload. sync and serve use the network for your self-hosted team server; runtime inspect also uses it.

How accurate are the cost figures?

Costs are estimates at public pay-as-you-go prices from a vendored LiteLLM table, not the amount you pay. When LiteLLM stops listing a model, assaio keeps the last price LiteLLM published for it; the vendor may no longer offer that rate, and doctor counts such models. Long-context premiums are not modeled, so very long sessions are underestimated. A model missing from the price table shows —, never $0, and is excluded from totals. reconcile compares a downloaded billing export offline and labels the remainder unexplained.

Does assaio rank or monitor individual developers?

assaio builds no ranking and refuses --by member in every format. On the team server, a member panel shows engagement while output and spend stay the team's total. Members have stable pseudonyms by default. report --identify names individuals and says so in its output.

Can assaio tell me whether AI-written code lasts?

Only directionally. survival checks how much code changed by recent commits remains in HEAD, without attributing lines to individual AI sessions. evidence reports session-to-commit candidates as matched, ambiguous, or unmatched, with coverage, method, and confidence. A match does not establish that a session caused a commit. Impact is not shipped.

Which AI coding tools does assaio support?

assaio reads Claude Code, Codex CLI, Gemini CLI, GitHub Copilot CLI, Cline, and Antigravity CLI. Five share one cost basis; Antigravity CLI contributes activity only because its logs have no token counter. Out-of-tree plugins in any language can add sources.

Is assaio free?

Yes. assaio is open source under Apache-2.0. It runs as one static binary and needs no account for local analysis.
